# Credit-Card-Fraud-Detection
Machine learning project for detecting fraudulent credit card transactions using Random Forest classification.

The dataset contains credit card transactions labeled as legitimate or fraudulent. The dataset is not included in this repository.
[Dataset link in the site: https://www.geeksforgeeks.org/machine-learning/ml-credit-card-fraud-detection/] 

Project Goals:
- Explore the dataset
- Investigate class imbalance
- Train a Random Forest classifier
- Evaluate the model using multiple metrics
- Compare a baseline Random Forest with a class-weighted Random Forest

The class-weighted model produced only a small difference compared with the baseline model on the test set.
This demonstrates that class weighting does not necessarily produce a dramatic improvement on every dataset.
